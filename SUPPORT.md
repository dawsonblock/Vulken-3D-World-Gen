# Support

## Getting Help

### 🐛 Bug Reports
- **GitHub Issues**: [Report bugs and issues](../../issues)
- **Security Issues**: See [SECURITY.md](SECURITY.md) for security-related concerns
- **Feature Requests**: [Suggest new features](../../issues/new?template=feature_request.md)

### 💬 Community Support
- **Discussions**: [GitHub Discussions](../../discussions) for general questions and community interaction
- **Documentation**: Check [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md) and [README.md](README.md)

### 📝 Before Reporting Issues

1. **Search existing issues** to avoid duplicates
2. **Check the documentation** for common solutions
3. **Provide detailed information**:
   - Operating system and version
   - GPU and driver version
   - Vulkan SDK version
   - Build configuration
   - Steps to reproduce
   - Expected vs actual behavior

### 🔧 Development Support

- **Build Issues**: See [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md)
- **Contributing**: See [CONTRIBUTING.md](CONTRIBUTING.md)
- **Code of Conduct**: See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

### 📊 Performance Issues

Include the following when reporting performance issues:
- GPU model and driver version
- Performance monitoring output (if available)
- System specifications (CPU, RAM, storage)
- Benchmark results or profiling data

## Response Times

- **Critical security issues**: 24-48 hours
- **Bug reports**: 3-7 days
- **Feature requests**: 1-2 weeks
- **General questions**: 1-7 days

Response times may vary based on maintainer availability and issue complexity.
