# Sample Textures

This directory contains minimal sample textures for testing and demos.

All textures are procedurally generated or CC0 licensed.

## Files

- `test_pattern.png` - Simple checkerboard test pattern (64x64)
- `gradient.png` - RGB gradient texture (128x128) 
- `noise.png` - Procedural noise texture (256x256)

## Usage

These textures are automatically loaded by the asset system and used in various tests and demos.
